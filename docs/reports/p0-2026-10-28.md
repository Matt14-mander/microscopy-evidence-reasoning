# P0-1 与 P0-2 实测报告

验证日期：2026-10-28。本次在本机完成真实模型 smoke test、全量 MicroVQA 数据审计和开发/测试划分，没有使用租赁 GPU 或付费 API。

## 1. 结论

**P0-1 已通过**：Qwen2.5-VL-3B-Instruct 在 RTX 4070 Laptop 上以 NF4 4-bit、BF16 计算运行，6 道开发样本的原图与 Text-only 共 12 次调用全部完成，12 个响应全部通过结构化 JSON 解析，无 OOM。

**P0-2 已通过**：固定数据版本的 1042 题全部通过行与图片检查。根据官方图片组和精确 RGB 图片重复关系合并后，得到 226 个组；开发集 206 题/45 组，测试集 836 题/181 组。两集合在样本 ID、合并组和精确图片哈希上均无交叉。

本报告证明运行链路和分组约束可行，不提供 benchmark 准确率或研究假设检验结论。

- 模型加载约 21.87 秒。
- 12 次请求平均 6.44 秒，中位数 6.57 秒，总计 77.28 秒；范围 3.51–9.77 秒。

- 12/12 调用执行成功、12/12 输出可解析；主动弃答 0 次。

请求耗时包含 processor 和生成，不包含下载、全量数据校验、样本图片解码与模型加载。显存读数是本模型推理阶段的 PyTorch 分配/保留量，不是 Windows 显卡总占用，也不是模型加载过程的峰值。样本数量很小，不能直接把这些耗时外推为全量实验保证。
