# Proposal 写作与最终提交计划

适用范围：课程或学位研究项目。Proposal 截止 2026-11-24；具体模板、语言、页数、评分标准和最终报告截止日尚待确认。以下结构为建议，不替代课程要求。

## 1. Proposal 的核心叙事

**问题**：显微镜多模态问答中的正确答案并不能单独说明模型如何使用图像，也不能说明输入质量降低时模型是否知道自己的答案不可靠。

**研究范围**：使用 MicroVQA，在不改变题目和选项的条件下比较原图、无图、图像模糊和降采样；评价准确率、置信度与选择性作答行为。

**可行性**：以一个可在本机或短期租用设备上推理的开放 VLM 为起点，不训练模型，不依赖当前不可获得的专家区域标注。基于已有数据/推理/评估代码，通过小样本真实运行估计正式实验资源。

**拟交付价值**：一套有固定样本划分、受控输入条件和组级配对分析的显微镜 VLM 评估结果，以及可重建报告的实验系统。

**边界**：本研究检测输入条件与模型行为之间的关系，不直接揭示内部因果推理，不把退化图像自动视为不可回答，也不将无图答对自动视为作弊。

## 2. 可用于改写的开题摘要草稿

> 本项目拟研究视觉输入缺失与图像退化对显微镜视觉语言模型问答表现及置信度的影响。研究以 MicroVQA 为评测基础，在固定模型、题目、选项和作答协议的条件下，构建原图、无图、高斯模糊与降采样等输入条件，比较样本级预测变化，并采用按图像组配对的统计分析评估差异及不确定性。项目将进一步考察模型自报置信度与预测错误之间的关系，并区分主动弃答、后处理拒答和输出解析失败。研究采用无需训练的低算力路线，先在开发集合上验证本地推理和实验参数，再在锁定测试集合上完成正式评估。预期产出包括研究报告、可复现代码、版本化配置、预测记录和由预测重建的图表。本项目不依赖专家区域标注，结论将限定在所选模型、数据子集与输入操作范围内。

此段为计划性文字，不包含已观察结果。写入正式 proposal 时补充课程格式要求与相关引用；预实验完成后另加真实结果，不将 mock 数字填入摘要。

## 3. 建议篇章与需要的材料

在课程没有指定模板时，可先按约 5–7 页正文准备，再按实际要求压缩；这不是已确认页数。

| 部分 | 要回答的问题 | 所需材料 | 写作状态要求 |
| --- | --- | --- | --- |
| Title / Abstract | 研究什么、如何验证、为什么可完成？ | 暂定题目、RQ、实验路线 | 全部用与完成状态一致的时态 |
| Background / Motivation | 为什么关注显微镜 VLM 的输入依赖和可靠性？ | MicroVQA 原文、VQA grounding 和可靠性研究 | 引用来源，避免泛泛描述“大模型很重要” |
| Related Work | 哪些问题别人已经研究？本项目具体补充什么？ | 文献对照表 | 不把缺图测试、遮挡或弃答宣称为首次提出 |
| Research Questions | 哪些可观测量能回答问题？ | RQ1–RQ3、主终点与次要分析 | 一个主问题支撑闭环，避免互不相干的多个方向 |
| Methodology | 数据、模型、输入条件、评价与统计如何固定？ | split、protocol、实验矩阵、指标公式 | 强制作答与弃答协议分开；解释共享图片的分组 |
| Feasibility / Pilot | 为什么在现有资源下能完成？ | 真实 smoke、约 50 题预实验、耗时/显存 | 数值来自预测与日志；无真实结果就不写已验证 |
| Schedule / Risks | 何时完成、失败时如何缩减？ | 日期计划、8 GB 显存限制、无标注替代路线 | 不预设租机预算、专家资源或第二模型已就绪 |
| Expected Outcomes | 最终交付与成功标准是什么？ | 报告、代码、预测、图表与复现说明 | 期待可检验结论，不承诺显著提升 |

建议的正文论证顺序为：场景问题 → 已有工作 → 本项目范围 → 可检验问题 → 实验设计 → 可行性证据 → 交付和限制。项目代码目录只需简述，不能替代方法论。

## 5. 结果章节与图表设计

先确定每张图服务的问题，再实现作图。所有最终图注明模型版本、协议、样本范围、样本/图像组数量和误差条含义。

| 产物 | 内容 | 对应论点 |
| --- | --- | --- |
| Figure 1 | 数据 → 分组 → 模型请求 → 输入条件 → 预测 → 评估的流程图 | 实验设计可解释、可复现 |
| Table 1 | 数据审计、开发/测试划分、单/多图和任务构成 | 明确结论针对哪些样本 |
| Table 2 | 模型、revision、量化、输入像素预算、GPU、运行时长 | 明确资源和实现条件 |
| Table 3 | 六条件准确率、无效输出率、confidence 可用比例 | 核心比较，避免隐藏格式或缺失数据问题 |
| Figure 2 | 原图与其他条件的配对差值及图像组 bootstrap CI | 回答 RQ1/RQ2；比单独柱形图更直接 |
| Figure 3 | 两类退化的强度–准确率/错误风险曲线 | 区分退化类型和非单调变化；不假设不同操作强度等价 |
| Figure 4 | 校准或风险–覆盖率图 | 回答 RQ3，同时显示可比较的覆盖率范围 |
| Case panel | 按预设作答转移类别选取少量例子 | 解释现象，不能用个例替代总体证据 |

没有专家时，个例只描述“输入发生何种变化、预测如何变化、是否匹配 benchmark 标签”。不要自行宣布细胞病理机制、真实生物学原因或关键结构已经被模型理解。

结果写作模板：

> 在锁定的 [N] 个问题、[G] 个图像组上，模型 [checkpoint/量化] 在 [协议] 下，原图准确率为 [值]，无图准确率为 [值]，配对差值为 [值] 个百分点，图像组 bootstrap 95% CI 为 [下限，上限]。该结果说明 [受输入条件限定的解释]。由于 [相关限制]，本实验不能据此判断 [更强但未被验证的主张]。

占位符只能由真实结果替换；CI 跨 0 时不能使用“显著优于”。没有差异也是有效结果，但要结合不确定性、预处理强度与模型能力讨论。

## 7. 最终代码与结果交付

建议在最终阶段生成一个归档目录；下列文件是待实现/待生成的交付规范，不是当前已存在文件：

```text
submission/
  README.md                  从安装到复现表图的步骤
  report.pdf                 最终报告
  report-source/             报告源文件及参考文献
  protocol.json              冻结的研究协议和主要比较
  data_manifest.json         官方数据 revision、内部划分与图像组
  environment.lock.txt       对应运行平台的实际依赖记录
  experiments.csv            run_id、模型、条件、split、状态、结果路径
  configs/                   展开后的实际配置
  predictions/               完整逐样本原始/解析输出及失败记录
  metrics/                   汇总指标、配对统计、分组计数
  tables/                    论文使用的 CSV
  figures/                   PDF/PNG 图表及输入索引
  CHECKSUMS.sha256            所有交付文件校验和
```

先实现“从预测重建图表”，再验证“从图像重跑模型”。复现图表不应要求再次付费、下载模型或联网。不要把本机环境里不相关的包当作科学依赖；正式运行尽量在干净环境复现，并保存平台相关安装说明。

原始图像、模型权重是否随包分发，应按其实际许可证与课程要求决定；默认提供官方下载说明、版本和校验信息。代码、少量配置和必要文档进入 Git，大型预测/图片通过明确的交付归档保存，不靠临时 `outputs/` 目录作为唯一备份。

最终核验：

- [ ] 所有表图能追溯到具体预测、配置和数据 split。
- [ ] 指标脚本可从预测独立运行；同一预测重算得到一致结果。
- [ ] 完整模型运行或子集运行的范围明确，不把子集成绩标成全量分数。
- [ ] 失败样本、无效输出、未补齐条件和筛选规则均被记录。
- [ ] 报告同时呈现不支持假设的结果，不根据正负结论挑选样本。
- [ ] 随机干预、生成和统计种子分开记录；共享图像相关性有处理。
- [ ] 如果仅有一个模型，结论明确限于该模型和版本。
- [ ] 归档后在新目录按 README 复现一次表图，验证路径不依赖开发者机器。
